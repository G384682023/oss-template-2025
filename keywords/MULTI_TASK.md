# [マルチタスク]

## 説明

マルチタスクとは、CPUが高速にタスクを切り替えることで、複数の処理が同時に動いているように見せる仕組みである。
これにより、音楽を再生しながら文書作成を行うなど、効率的な操作が可能になる。
もしマルチタスクがなければ、1つの処理が終わるまで他の作業ができず、作業性が大きく低下してしまう。マルチタスクはOSの中心的な技術であり、プロセス管理やスレッド管理、スケジューリングと密接に結びつき、コンピュータの応答性と安定性を支えている。
